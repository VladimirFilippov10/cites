Руководство пользователя для сотрудников

1. Введение
Данное руководство описывает основные функции и возможности системы для сотрудников автосалона. Включает авторизацию, регистрацию, работу с автомобилями, клиентами, продажами и выкупами.

2. Регистрация
- Откройте страницу регистрации (обычно ссылка "Регистрация" в верхнем меню).
- Заполните поля:
  - Логин: введите уникальный логин.
  - Код регистрации: введите код, предоставленный администратором.
  - Пароль: введите пароль.
  - Подтверждение пароля: введите пароль повторно.
- Нажмите кнопку "Зарегистрироваться".
- После успешной регистрации появится сообщение об успешном создании аккаунта.
- Перейдите на страницу авторизации для входа.

3. Авторизация
- Перейдите на страницу авторизации (ссылка "Вход" в верхнем меню).
- В поле "Логин" введите ваш логин.
- В поле "Пароль" введите ваш пароль.
- Нажмите кнопку "Войти".
- Если данные введены верно, вы попадете на главную страницу (рабочую доску).

4. Главная страница (Рабочая доска)
- После входа вы увидите главную страницу с меню вверху.
- Для перехода к разделам нажмите соответствующие пункты меню:
  - "Автомобили" — для управления автомобилями.
  - "Клиенты" — для управления клиентами.
  - "Выкуп автомобилей" и "Продажи" — для работы с заявками.
- В каждом разделе есть кнопки для добавления, редактирования и удаления записей.

5. Управление автомобилями
- Перейдите в раздел "Автомобили" через меню.
- Для добавления нового автомобиля нажмите кнопку "Добавить автомобиль" (обычно расположена сверху или снизу списка).
- Заполните форму:
  - Введите марку, модель, год выпуска и другие характеристики.
  - Загрузите фотографии автомобиля, нажав кнопку "Выбрать файл" или "Добавить фото".
- Нажмите кнопку "Сохранить" или "Добавить".
- Для редактирования автомобиля в списке нажмите кнопку "Редактировать" рядом с нужным автомобилем.
- Внесите изменения и нажмите "Сохранить".

6. Управление клиентами
- Перейдите в раздел "Клиенты" через меню.
- Для добавления клиента нажмите кнопку "Добавить клиента".
- Заполните форму с данными клиента: ФИО, контактные данные, статус.
- Нажмите "Сохранить".
- Для редактирования клиента нажмите "Редактировать" рядом с нужным клиентом.
- Внесите изменения и сохраните.

7. Продажи и выкупы автомобилей
- Для создания заявки на продажу автомобиля перейдите в раздел "Продажи".
- Нажмите кнопку "Новая продажа".
- Заполните форму заявки и нажмите "Сохранить".
- Для создания заявки на выкуп автомобиля перейдите в раздел "Выкуп автомобилей".
- Нажмите "Новый выкуп".
- Заполните форму и сохраните.
- Для просмотра и управления заявками используйте кнопки "Просмотр" или "Редактировать" рядом с каждой заявкой.

8. Дополнительные функции
- Управление сотрудниками и их ролями доступно в разделе "Сотрудники".
- Для создания нового сотрудника нажмите "Добавить сотрудника", заполните форму и сохраните.
- Формирование отчетов доступно в разделе "Отчеты".
- Для генерации отчета выберите период и нажмите "Сформировать".

9. Заключение
Система предназначена для автоматизации работы автосалона, обеспечивая удобный интерфейс и контроль всех бизнес-процессов.

Для более детальной информации рекомендуется использовать скриншоты интерфейса, которые можно добавить в это руководство.
